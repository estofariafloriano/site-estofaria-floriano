ESTOFARIA FLORIANO — SITE INSTITUCIONAL

ARQUIVOS
- index.html: estrutura, conteúdo e metadados SEO.
- style.css: identidade visual, layout responsivo e animações.
- script.js: menu mobile, revelação de seções e galeria ampliável.

COMO ABRIR NO COMPUTADOR
1. Extraia o ZIP para uma pasta.
2. Abra index.html com dois cliques no Chrome, Edge ou Firefox.
3. Para editar, abra os três arquivos em um editor de texto ou VS Code.

PUBLICAÇÃO GRATUITA
NETLIFY: entre em https://app.netlify.com/drop e arraste a pasta extraída (ou uma pasta com os três arquivos) para a área indicada. O Netlify fornecerá um endereço público após concluir o envio.

GITHUB PAGES:
1. Crie uma conta em https://github.com e um repositório novo.
2. Envie index.html, style.css e script.js para a raiz do repositório.
3. Abra Settings > Pages, selecione Deploy from a branch, escolha a branch main e a pasta /(root), e salve.
4. Aguarde a publicação e use o endereço exibido em Settings > Pages.

Antes de publicar, confira telefone, textos, imagens, links e dados comerciais.
